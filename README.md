# OneFrameRaces

`v1.0.2` · Paper `1.21.11` · Java `21`

Плагин системы рас для сервера Minecraft на Paper. Даёт игрокам выбираемую (администратором) расу — постоянный набор характеристик (HP, броня), пассивных эффектов и активных способностей, который держится на игроке всё время, переживает выход из игры и рестарт сервера, и восстанавливается автоматически при входе и респавне.

Помимо самих рас, плагин вводит набор общемировых правил, действующих на всех игроков сразу (гипоксия на высоте, отсутствие дропа при добыче deepslate, смертельные барьерные зоны, запрет ряда чар, отключённые порталы и торговля, принудительная нормализация ников) — часть их можно обойти только конкретной расой через явное исключение.

## Возможности

- **Система рас** — постоянное состояние игрока (не предмет, не зелье), 8 встроенных рас в 4 категориях (`HUMAN`, `MERMAN`, `DEMON`, `SPECIAL`, зарезервирована `MONSTER`), у каждой — свой набор HP/брони/пассивок/способностей и лимит одновременных обладателей.
- **Расширяемость через `ServiceLoader`** — новые расы добавляются без правки кода плагина: реализуйте интерфейс `RaceProvider`, положите jar с `META-INF/services/...RaceProvider` в `plugins/OneFrameRaces/races/`, выполните `/race reload`.
- **Глобальные правила мира** — 7 правил, применяемых ко всем игрокам, с возможностью точечного исключения для конкретных рас через флаги.
- **Именные предметы** — сигнатурные предметы расы (рог, когти, панцирь, ботинки) выдаются автоматически, неразрушимы, броня несъёмная (Проклятие несъёмности); их нельзя выбросить, положить в любой контейнер или передать; при смерти удаляются и заново выдаются на респавне.
- **Датапак высоты** — опциональный датапак в комплекте поднимает потолок строительства оверворлда до Y=512 (см. [datapack/README.md](datapack/README.md)).
- **Единый scheduler** — все периодические проверки плагина идут через один `runTaskTimer` раз в секунду, а не десяток параллельных таймеров.
- **Персистентность** — назначения игрок→раса хранятся в YAML-файле с атомарной записью, переживают рестарт сервера.

## Установка

**Требования:** Paper `1.21.11` (или совместимая сборка того же минорного релиза), Java `21`.

1. Скачайте (или соберите из исходников, см. ниже) `OneFrameRaces-1.0.2.jar`.
2. Положите файл в папку `plugins/` вашего сервера.
3. Запустите/перезапустите сервер.
4. При первом запуске плагин создаст:
   - `plugins/OneFrameRaces/config.yml` — настройки (см. таблицу ниже);
   - `plugins/OneFrameRaces/playerdata/races.yml` — назначения игрок→раса (появится после первого `/race set`).
5. (Опционально) для сторонних рас создайте папку `plugins/OneFrameRaces/races/` и положите туда jar-файлы дополнительных модулей.
6. (Опционально) чтобы поднять потолок строительства до Y=512, скопируйте `datapack/oneframe-height` в `world/datapacks/` и перезапустите сервер — подробности в [datapack/README.md](datapack/README.md).

## Быстрый старт

```
/race list                       # посмотреть все доступные расы
/race info forester              # детали конкретной расы: HP, броня, способности
/race set Steve forester         # назначить игроку Steve расу Forester
/race get Steve                  # посмотреть текущую расу игрока
/race clear Steve                # снять расу, вернуть ванильные характеристики
```

## Расы

| Раса | Категория | HP | Броня | Ключевая тема |
|---|---|---|---|---|
| `forester` (Forester) | HUMAN | 24 | 0 | Luck, двойной приплод, шанс книги с рыбалки, иммунитет к яду, Speed при уроне |
| `blacksmith` (Blacksmith) | HUMAN | 16 | 2 | Strength, бесплатная наковальня, иммунитет к взрывам, Weakness при взмахе (даунсайд) |
| `marinian` (Marinian) | MERMAN | 20 | 0 | Инверсия утопления, бонусы в воде/дожде, рог "Battle Cry" (баф по площади), когти с Silk Touch |
| `fugu` (Fugu) | MERMAN | 20 | 6 | Resistance III + Slowness IV, ядовитое касание, черепаший панцирь с Thorns III |
| `blazeborn` (Blazeborn) | DEMON | 26 | 0 | Fire Resistance, урон вне Nether и от воды, поджигает всё вокруг, взрыв при собственной смерти, не ест/не пьёт |
| `warlock` (Warlock) | DEMON | 18 | 2 | Иммунитет к Wither, вампирический удар, незеритовые ботинки с Soul Speed III |
| `skyborn` (Skyborn) | SPECIAL | 20 | 0 | Только иммунитет к высотной гипоксии |
| `underground` (Underground) | SPECIAL | 20 | 0 | Заготовка, без уникальной механики |

Полное описание каждой способности — `/race info <раса>` в игре, либо построчный разбор в [WALKTHROUGH.md](WALKTHROUGH.md).

## Глобальные правила

Действуют на всех игроков, если раса явно не освобождена (см. столбец "Исключения" в разборе каждой расы):

| # | Правило | Исключение |
|---|---|---|
| 1 | Высотная гипоксия выше `altitude-hypoxia-y` | Skyborn |
| 2 | Deepslate и его руды — без дропа/опыта | Merman (`marinian`, `fugu`) |
| 3 | Смерть от `barrier-death-seconds` секунд непрерывного контакта с barrier-блоком (кроме creative/spectator) | нет |
| 4 | Запрещены Silk Touch, Fortune, Luck of the Sea, Protection (стол зачарования, книги в инвентаре, лут) | именные предметы расы (напр. когти Marinian) |
| 5 | Отключён Край (платформа, активация глазом, телепорт); Nether-порталы работают | нет |
| 6 | Отключена торговля с жителями/странствующими торговцами | нет |
| 7 | Принудительная нормализация ника (чат + tab) к реальному имени аккаунта | нет |

## Команды

Базовая команда `/race`.

| Команда | Описание | Право |
|---|---|---|
| `/race` | Список подкоманд | `oneframe.race.self` |
| `/race list` | Все расы: id, категория, HP, броня | `oneframe.race.self` |
| `/race info <раса>` | Детали расы + список способностей | `oneframe.race.self` |
| `/race get [игрок]` | Текущая раса игрока (по умолчанию — своя) | `oneframe.race.self` |
| `/race set <игрок> <раса>` | Назначить расу (с проверкой лимита) | `oneframe.race.admin` |
| `/race clear <игрок>` | Снять расу | `oneframe.race.admin` |
| `/race reload` | Перечитать реестр рас (включая сторонние модули) и назначения с диска | `oneframe.race.admin` |

`oneframe.race.self` выдано всем по умолчанию, `oneframe.race.admin` — только операторам (`op`). Все подкоманды поддерживают Tab-автодополнение.

## Конфигурация

`plugins/OneFrameRaces/config.yml`:

| Параметр | По умолчанию | Описание |
|---|---|---|
| `settings.enforce-names-every-ticks` | `100` | Как часто (в тиках) принудительно нормализовать ник в чате/tab |
| `settings.altitude-hypoxia-y` | `300` | Y-координата, выше которой начинается высотная гипоксия |
| `settings.barrier-death-seconds` | `10` | Сколько секунд непрерывного контакта с barrier-блоком убивает игрока |
| `settings.low-y-ore-floor` | `0` | **Зарезервировано, не используется** (см. "Известные ограничения") |

Изменения `config.yml` применяются только при **рестарте сервера** — `/race reload` их не подхватывает (перечитывает только реестр рас и файл назначений).

## Сборка из исходников

```bash
./gradlew build
```

Собранный jar появится в `build/libs/OneFrameRaces-1.0.2.jar`. Требуется Java 21 (Gradle toolchain скачает нужную версию автоматически, если её нет локально) и доступ к `repo.papermc.io` для зависимости `paper-api`.

## Как добавить свою расу

1. Реализуйте интерфейс `dev.oneframe.races.core.RaceProvider` в отдельном jar-проекте (зависимость — `paper-api` + скомпилированный класс `RaceProvider`, доступный из основного jar плагина). Обязателен public no-args конструктор.
2. Добавьте в свой jar файл `META-INF/services/dev.oneframe.races.core.RaceProvider`, где укажите полное имя вашего класса.
3. Положите готовый jar в `plugins/OneFrameRaces/races/` и выполните `/race reload` — раса появится в `/race list` без перезапуска сервера.

Подробности контракта (`hp()`, `sp()`, `exemptionFlags()`, `abilities()`, `namedItems()`) и то, как способности диспетчеризуются к событиям Bukkit — в [WALKTHROUGH.md, раздел 3](docs/walkthrough/03-core-interfaces.md) и [раздел 13](docs/walkthrough/13-listeners.md).

## Известные ограничения / TODO

- **Underground** — раса-заготовка, пока без уникальной механики (только базовые HP/броня, полная интеграция с инфраструктурой). Добавление способности — вопрос новых классов в пакете `races/special`, без изменений остальной архитектуры.
- **`low-y-ore-floor`** — параметр конфигурации зарезервирован под будущее правило "пол по Y для добычи руды", контракт (`ExemptionFlag`) уже готов, логика не реализована.
- **Вампирический удар Warlock** — лечение при ударе намеренно зафиксировано на `6.0` HP (задокументированное как "известное поведение: эффект удвоен" — это не баг, при рефакторинге не нужно "исправлять" до 3.0).
- **`/race reload` не перечитывает `config.yml`** — только реестр рас и `races.yml`; изменения настроек (`altitude-hypoxia-y` и т.п.) требуют полного рестарта сервера.
- **`/race get <офлайн-игрок>`** не поддерживается — команда ищет только среди подключённых игроков.
- Полная защита именных предметов от передачи не абсолютна (блокируются основные пути — клик/драг в чужой инвентарь, хоппер, подбор чужого с земли, торговля), периодическая зачистка раз в секунду — подстраховка для остального.

Подробный список архитектурных решений и точек расширения — в [CLAUDE.md](CLAUDE.md).
