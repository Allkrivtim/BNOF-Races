# Датапак: высота строительства до Y=512

Высота мира — свойство типа измерения (dimension type), плагин изменить её на лету **не может**. Это делается датапаком, переопределяющим `minecraft:overworld`.

## Плагин ставит его сам

Начиная с версии 1.1.0 **ничего копировать вручную не нужно**: при первом запуске плагин создаёт `world/datapacks/oneframe-height/` сам и пишет в лог:

```
[OneFrameRaces] Installed the 'oneframe-height' datapack (overworld build height -> Y=512).
RESTART THE SERVER ONCE for it to take effect - dimension types are read at world load.
```

После этого нужен **один перезапуск сервера** — типы измерений читаются только при загрузке мира. Повторно плагин папку не трогает: если она уже есть, установка пропускается, ваши правки не перетираются.

Проверка после перезапуска:
```
/forceload add 0 0
/setblock 0 500 0 minecraft:stone
```
Блок должен поставиться (проверено: Y=500 и Y=511 работают, Y=512 — уже за границей, потолок 511 включительно).

## Ручная установка

Копия датапака лежит здесь, в `oneframe-height/` — на случай, если нужно поставить его до запуска плагина или в другой мир:

```
world/datapacks/oneframe-height/pack.mcmeta
world/datapacks/oneframe-height/data/minecraft/dimension_type/overworld.json
```

## Как это устроено

`min_y: -64` + `height: 576` = потолок Y=511 (высота мира обязана быть кратной 16, поэтому берётся 576, а не «ровно 500»). Существующие чанки безопасно расширяются вверх пустотой — мир пересоздавать не нужно. При первой загрузке старых чанков сервер напишет пачку `Ignoring heightmap data for chunk ... size does not match` — это нормально, карты высот просто пересчитываются под новый размер.

## Связь с плагином

Глобальное правило 1 (высотная гипоксия, `settings.altitude-hypoxia-y: 300`) продолжает действовать: выше Y=300 у всех, кроме Skyborn, истощается кислород, а затем идёт урон. То есть зона 300–511 — фактически территория Skyborn. Если строить там должны все, поднимите `altitude-hypoxia-y` в `config.yml` (изменение подхватится после перезапуска — `/race reload` конфиг не перечитывает).
