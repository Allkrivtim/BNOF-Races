# Датапак: высота строительства до Y=512

Высота мира — свойство типа измерения (dimension type), плагин изменить её **не может**. Это делается датапаком, переопределяющим `minecraft:overworld`.

Здесь лежит готовый датапак `oneframe-height`, поднимающий верхнюю границу оверворлда с Y=320 до **Y=512** (просили ≥500; высота мира обязана быть кратной 16, поэтому 512: min_y −64 + height 576 = 512).

## Установка

1. Скопируйте папку `oneframe-height` целиком в `world/datapacks/` на сервере (где `world` — папка основного мира):
   ```
   world/datapacks/oneframe-height/pack.mcmeta
   world/datapacks/oneframe-height/data/minecraft/dimension_type/overworld.json
   ```
2. Полностью перезапустите сервер (`/reload` недостаточно для dimension type).
3. Проверьте в игре: `/setblock ~ 500 ~ minecraft:stone` — блок должен поставиться.

Существующие чанки безопасно расширяются вверх пустотой — мир пересоздавать не нужно. Если при старте сервер напишет предупреждение о версии пака — это нормально, пак всё равно загрузится (формат указан с запасом).

## Связь с плагином

Глобальное правило 1 (высотная гипоксия, `settings.altitude-hypoxia-y: 300`) продолжает действовать: выше Y=300 у всех, кроме Skyborn, истощается кислород. То есть зона 300–512 — фактически территория Skyborn.
