# Высотный датапак BNOF-Races

## Почему плагину нужен датапак

Плагин управляет игроками и событиями уже после загрузки мира. Максимальная высота строительства хранится в `dimension_type` и читается Minecraft раньше, поэтому Paper API не может изменить её во время работы. Датапак — штатный механизм Minecraft для такого изменения; отдельно устанавливать его не надо.

## Что делает установщик

- выбирает первый загруженный мир с окружением `NORMAL`, а не просто первый мир в списке;
- записывает пакет в `<overworld>/datapacks/oneframe-height/`;
- сверяет оба файла побайтно и восстанавливает устаревшую или неполную копию;
- не трогает уже корректную копию;
- отключается через `settings.height-datapack-enabled: false`.

Имя папки `oneframe-height` оставлено специально для обновления старых серверов: переименование создало бы второй пакет, одновременно переопределяющий Overworld.

## Совместимость

Пакет предназначен строго для Minecraft Java 1.21.11 и использует data pack format `94.1`. JSON типа измерения взят из vanilla 1.21.11; изменены только:

```json
"height": 576,
"logical_height": 576
```

При `min_y: -64` верхний допустимый блок находится на Y=511. После первой установки и после обновления содержимого пакета сервер нужно перезапустить, потому что текущий уже загруженный мир изменить нельзя.

Единственный исходник пакета хранится внутри jar: `src/main/resources/datapack/bnof-races-height/`. Отдельная ручная копия удалена, чтобы она не расходилась с установщиком.
