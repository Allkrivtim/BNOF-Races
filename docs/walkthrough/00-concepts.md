# 00. Базовые понятия

BNOF-Races — Paper-плагин: `BnofRacesPlugin#onEnable` вызывается сервером после загрузки миров. Поэтому обычные механики реализуются Bukkit-событиями и задачами, но тип измерения меняется отдельным датапаком до следующего старта.

Раса представлена `RaceProvider`. Провайдер содержит id, отображаемое имя, категорию, лимит, HP, броню, способности и именные предметы. Встроенные и сторонние реализации обнаруживаются `ServiceLoader` по файлу `META-INF/services/dev.oneframe.races.core.RaceProvider`.

Состояние предмета хранится в `PersistentDataContainer`. Полная идентичность включает UUID владельца, id расы, ключ предмета и версию схемы. Одного красивого имени или типа материала недостаточно.

Все вызовы Bukkit API выполняются на основном потоке. Секундный heartbeat общий, но каждая операция защищена отдельно: исключение одной способности не прерывает обработку остальных игроков.
