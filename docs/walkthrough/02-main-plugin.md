# 02. Главный класс

`BnofRacesPlugin` выполняет запуск в следующем порядке:

1. копирует legacy-данные OneFrameRaces, если нового `races.yml` ещё нет;
2. загружает config и провайдеры;
3. создаёт storage, `NamedItemService` и `RaceManager`;
4. регистрирует heartbeat, listeners, правила и `/race`;
5. проверяет/устанавливает датапак.

На каждом секундном проходе один `AbilityContext` переиспользуется для всех игроков. Способности, гипоксия, барьер, запрещённые чары и согласование предметов запускаются через отдельные `safely`-границы.

При выключении heartbeat отменяется, а актуальная карта назначений ещё раз сохраняется. Датапак устанавливается уже после загрузки мира и потому начинает действовать только после рестарта.
