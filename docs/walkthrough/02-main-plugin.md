# 02. Главный класс

`BnofRacesPlugin` выполняет запуск в следующем порядке:

1. копирует legacy-данные OneFrameRaces, если нового `races.yml` ещё нет;
2. загружает config и провайдеры;
3. создаёт storage, `NamedItemService`, `RaceManager` и высотный `BreathingService`;
4. регистрирует heartbeat, listeners, правила и `/race`;
5. проверяет/устанавливает датапак.

Общий scheduler работает каждый серверный тик для точной высотной гипоксии. Способности, барьер, запрещённые чары и предметы сохраняют секундный интервал; бесконечные пассивы дополнительно обновляются раз в 6000 тиков. Один `AbilityContext` переиспользуется для всех игроков прохода. Каждая операция запускается через отдельную `safely`-границу.

При выключении heartbeat отменяется, управляемый гипоксией воздух игроков восстанавливается, а актуальная карта назначений ещё раз сохраняется. Датапак устанавливается уже после загрузки мира и потому начинает действовать только после рестарта.
