# 05. TickService

`TickService` создаёт одну Bukkit-задачу с периодом один тик. Интервалы регистраций тоже задаются в серверных тиках: дыхание выполняется каждый тик, большинство способностей и правил — раз в 20 тиков, общий refresh пассивов — раз в 6000 тиков. Задачи хранятся в обычном `ArrayList`, потому что регистрация и выполнение происходят на одном серверном потоке.

`start()` защищён от двойного запуска, `stop()` отменяет heartbeat, а `TickTaskHandle` позволяет снять отдельную регистрацию. Исключение верхнеуровневой задачи логируется самим сервисом; внутри основного player-pass операции дополнительно изолированы по игроку и правилу.

Настройка `enforce-names-every-ticks` применяется напрямую, без округления до секунд.
