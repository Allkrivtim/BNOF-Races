# 05. TickService

`TickService` создаёт одну Bukkit-задачу с периодом 20 тиков. Задачи регистрируются в обычном `ArrayList`, потому что регистрация и выполнение происходят на одном серверном потоке.

`start()` защищён от двойного запуска, `stop()` отменяет heartbeat, а `TickTaskHandle` позволяет снять отдельную регистрацию. Исключение верхнеуровневой задачи логируется самим сервисом; внутри основного player-pass операции дополнительно изолированы по игроку и правилу.

Интервал настройки в Minecraft-тиках переводится в секундные проходы округлением вверх: `(ticks + 19) / 20`.
