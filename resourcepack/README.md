# BNOF-Races Resource Pack

`BNOF-Races/` — объединённый исходник предоставленного серверного ресурспака и ресурсов BNOF-Races.

Пак глобально заменяет текстуру `minecraft:milk_bucket` на флакон и переводит его ванильный ключ имени как «Слеза чистоты». Отдельный предмет, `CustomModelData` и `item_model` не используются: существующие и выданные командой milk bucket тоже получают новый вид.

Поддерживаемые локализации имени: русский, английский, украинский, белорусский, немецкий, французский, испанский, польский, бразильский португальский, турецкий, упрощённый китайский, японский и корейский.

`./gradlew build` создаёт готовый архив `build/libs/BNOF-Races-ResourcePack.zip`. Папка `source/` содержит исходное сгенерированное изображение и в архив не входит.
